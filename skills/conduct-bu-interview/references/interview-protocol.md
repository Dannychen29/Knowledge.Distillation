# Interview protocol

## Question order

1. Confirm need, role, target user, outcome, scope, constraints and evidence permission.
2. Obtain one end-to-end ordinary case.
3. Confirm the full process landscape.
4. Prioritize deep-dive areas using impact, risk, ambiguity, exception frequency and reliance on experience.
5. Probe one concrete decision or exception at a time.

## Adaptive questioning

For each answer, decide whether it establishes the actor, trigger, input, action, decision, rationale, output and exception. Ask only for the missing element that most affects reconstruction.

Prefer concrete prompts such as:

- 「請用最近一個實際案例說明你看到什麼，接著做了什麼？」
- 「什麼情況會讓你做出不同決定？」
- 「這項判斷來自規範、固定計算、經驗法則，還是個人偏好？」
- 「新人最容易在哪裡判斷錯？」

Do not dump a questionnaire. Do not ask the participant to decide which Skill or API should be built.
